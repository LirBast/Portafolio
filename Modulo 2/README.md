# Módulo 2 – Libros & Bytes

Este proyecto corresponde al **Módulo 2 del Bootcamp de Ciencia de Datos**.  
El objetivo fue realizar un análisis exploratorio de datos y aplicar técnicas de limpieza para obtener un dataset utilizable.

## Contenido
- `Libros & Bytes consolidado2.py`: Script en Python con el análisis.
- `M2_Consolidado.rar`: Carpeta comprimida con los archivos del módulo.

## Tecnologías usadas
- Python (Pandas, Numpy, Matplotlib, Seaborn)
- Jupyter Notebook

## Resultados principales
- Se identificaron patrones en la distribución de libros vendidos.
- Se limpiaron valores faltantes y duplicados.
- Se construyeron gráficos exploratorios.
